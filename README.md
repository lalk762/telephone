# NEXUS CLIENT

Безопасный каркас клиентского Fabric-мода для Minecraft 1.21.11.

## Принципы безопасности
- Тренировочные функции предназначены только для локального одиночного мира.
- Нет автоматического наведения, автоматических атак или воздействия на других игроков.
- Нет обхода античита, скрытия модификации или вмешательства в сетевые проверки.
- Не собираются и не отправляются личные данные.
- В репозиторий не добавляются сторонние бинарные файлы и скачанные зависимости.

## Состояние
Сейчас добавлен минимальный исходный каркас и документированы ограничения безопасности. Это **не готовый JAR** и пока не полноценная реализация интерфейса. Сборка Fabric требует совместимых локально доступных Gradle/Fabric-зависимостей. Ничего не скачивается автоматически этим репозиторием.

## План безопасной реализации
1. Неон-фиолетовый интерфейс NEXUS.
2. Открытие/закрытие интерфейса клавишей Right Shift.
3. HUD с обычной информацией клиента.
4. Локальные тренировочные манекены только в одиночном мире.
5. Явные переключатели и безопасные значения по умолчанию.
